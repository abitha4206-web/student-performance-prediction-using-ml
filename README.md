# 🎓 Student Performance Prediction using Machine Learning

## 📌 Project Overview
This project predicts a student's exam performance using Machine Learning based on academic, personal, and lifestyle factors.

The application is developed using **Python**, **Flask**, and **Scikit-learn**, with a simple and responsive web interface.

---

## 🚀 Features

- Predicts student exam score
- User-friendly web interface
- Responsive design
- Machine Learning based prediction
- Fast and simple prediction

---

## 🛠️ Technologies Used

- Python
- Flask
- HTML
- CSS
- Scikit-learn
- Pandas
- NumPy

## ▶️ How to Run

1. Clone the repository
2. Install the required packages

```bash
pip install -r requirements.txt
```

3. Run the application

```bash
python app.py
```

4. Open your browser

```
http://127.0.0.1:5000
```
